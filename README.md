# get-proFI

Personal study app for tough FI MUNI courses: one "course" per subject with a roadmap, key deadlines, knowledge-gap tracking and drills. Local-only web app (React + TypeScript + Vite, data in IndexedDB).

## Development

```
npm install
npm run dev     # dev server
npm test        # unit tests
npm run lint
npm run build
```

Source slides/PDFs go to `sources/` (not versioned). Condensed course content lives in `content/<course-code>/`.
